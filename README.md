# Pati Veteriner — Veteriner Kliniği Randevu ve Hasta Takip Sistemi

Sakarya Üniversitesi · Web Programlama · 2026-2027 Güz Dönemi Proje Ödevi

ASP.NET Core MVC (.NET 10) ile geliştirilen bu proje; veteriner kliniklerinin hizmetlerini, hekimlerin uzmanlık alanlarını ve müsaitliklerini, evcil hayvanların muayene ve aşı geçmişini ve hayvan sahiplerinin randevularını yönetmek için hazırlanmaktadır.

Planlanan özellikler:

- Klinik, hizmet (süre/ücret) ve veteriner hekim yönetimi
- Hayvan sahibi üyeliği, evcil hayvan ve aşı kayıtları
- Müsaitlik ve çakışma kontrollü randevu sistemi (onay mekanizmalı)
- Admin, Veteriner ve Üye rolleri
- LINQ sorguları kullanan REST API
- Yapay zekâ asistanlarının çağırabileceği MCP (Model Context Protocol) sunucusu

Teknolojiler: ASP.NET Core MVC, C#, Entity Framework Core (Code First), SQLite, ASP.NET Core Identity, ModelContextProtocol.AspNetCore, Bootstrap 5, jQuery
